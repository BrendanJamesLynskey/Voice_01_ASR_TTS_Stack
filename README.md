# Voice 01 — The ASR &amp; TTS Stack

A deep-dive presentation covering the full voice pipeline from microphone to speaker: Whisper architecture and multilingual fine-tuning, streaming ASR services (Deepgram Nova-3, Soniox, Gladia, AssemblyAI Universal-2), TTS landscape (ElevenLabs, Cartesia Sonic, OpenAI TTS, PlayHT), latency-first design patterns, voice cloning capabilities and ethics, open-source alternatives (Coqui XTTS-v2, F5-TTS), and quality/latency/cost trade-off frameworks.
